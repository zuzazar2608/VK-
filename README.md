VK Автоответчик — инструкция (Chrome / Edge)

Что делает
Расширение наблюдает за новыми сообщениями в открытом чате веб-версии VK (vk.com или vk.ru). При включённом переключателе и совпадении имени собеседника в заголовке чата оно подставляет заданный ответ и отправляет его после указанной задержки. Код хранится локально в этой папке. При включении ИИ сообщение и выбранный личный контекст отправляются выбранному API-провайдеру.

Установка
1. Откройте страницу расширений браузера:
   Chrome: chrome://extensions
   Edge: edge://extensions
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку «VK Автоответчик» на рабочем столе (папка с manifest.json).
5. Перезагрузите вкладку VK, если она уже была открыта.

Настройка и запуск
1. Откройте веб-версию VK и нужный чат. Расширение не запускает настольное приложение VK и не работает, когда браузер/вкладка закрыты.
2. Нажмите значок расширения в браузере.
3. Укажите имя собеседника так, как оно показывается в заголовке чата.
4. Для ИИ включите «Получать ответ от ИИ». Для AI Gateway выберите соответствующий режим: Base URL заранее установлен как https://api.voidluv.com/v1. Вставьте свой секретный ключ и нажмите «Загрузить доступные модели», выберите модель из списка и нажмите «Сохранить». Если список не загружается, проверьте ключ и доступность шлюза в кабинете VoidLuv. Ключ хранится в локальном профиле браузера — не передавайте его другим людям. При включённом ИИ сообщения и заполненный личный контекст отправляются API VoidLuv. Можно выбрать Anthropic или GigaChat отдельно.
5. В блоке «Личные данные для ИИ» при необходимости укажите ФИО, блок, этаж, институт, группу, номер общежития и дополнительный контекст. Эти сведения сохраняются в настройках и добавляются к запросам как справочная информация. Заполняйте только необходимые данные: при включённом ИИ они передаются выбранному API-провайдеру. В поле «Инструкция для ИИ» укажите, каким тоном и в каком формате отвечать. В поле «Шаблон сообщения» задайте текст, например «+ {answer}»; {answer} заменяется ответом модели. Инструкция применяется только при включённом ИИ.
6. Установите задержку в миллисекундах. Для теста разумно начать с 3000–5000 мс.
7. Сначала проверьте на тестовом чате и только потом включите «Включить отправку» и нажмите «Сохранить настройки».
8. Чтобы остановить автоответ, снимите флажок и сохраните.

Дистанционное управление через Telegram
1. В настройках расширения заполните токен Telegram-бота и свой Chat ID, включите «Отправлять уведомление о срабатывании» и сохраните. Этот же Chat ID является единственным разрешённым для команд.
2. Откройте чат с ботом и отправьте /start. Команды поступают через long polling Telegram: обычно обрабатываются за несколько секунд; браузер должен быть запущен, а расширение установлено.
3. Команды: /status, /on, /off, /keywords текст, /senders имена через запятую, /prompt инструкция для ИИ, /reply шаблон (например /reply + {answer}), /mode once или /mode regular, /delay число миллисекунд.
4. Изменения записываются в локальные настройки и применяются без перезагрузки страницы VK. /prompt используется при включённом ИИ. Для отключения дистанционного управления отключите Telegram-уведомления или удалите токен из настроек.
5. Не передавайте токен Telegram-бота и не пересылайте команды третьим лицам. Если бот использует webhook, polling через getUpdates работать не будет — удалите webhook через настройки вашего Telegram-интегратора.

Важные ограничения и безопасность
- Это экспериментальное расширение: интерфейс VK может измениться, из-за чего распознавание сообщений/заголовка не сработает.
- Автоотправка — реальное действие: внимательно проверьте имя, шаблон и адресата до включения. Не оставляйте её включённой без присмотра, если ошибки могут причинить вред или смутить собеседника.
- Задержка не гарантирует правильность распознавания. Программа не отвечает на сообщения, которые уже были видны при загрузке страницы; для нового ответа должен появиться новый блок сообщения.
- Для обычного фиксированного ответа удалите {lastQuestion} и впишите нужный текст.
- Расширение не считывает пароль VK. API-ключ сохраняется локально в профиле браузера, но не является защищённым хранилищем; используйте отдельный ключ с минимальными правами и не делитесь профилем браузера.
- При включённом ИИ содержимое входящих сообщений передаётся выбранному API-провайдеру. Не используйте эту функцию для приватной переписки без согласия и проверки условий провайдера. Для GigaChat расширение получает OAuth access token по Authorization Key. Для Anthropic используется Messages API. После обновления расширения нажмите «Обновить» на странице расширений браузера и перезагрузите вкладку VK.
- В режиме «Одноразовый» после первой отправки автоответчик выключается. В режиме «Регулярный» он продолжает отвечать только на новые сообщения в открытом чате, если имя в заголовке совпадает с заданным. Перед отправкой расширение проверяет поле ответа и нажимает найденную видимую кнопку отправки; всё равно сначала проверьте на тестовом чате.
- После обновления расширения нажмите «Обновить» на странице расширений и перезагрузите вкладку VK. Если отправка снова повторяется, сразу выключите расширение целиком и не включайте до исправления.

- Чтобы удалить расширение, удалите его на странице расширений браузера. Файлы этой папки можно затем удалить вручную.
